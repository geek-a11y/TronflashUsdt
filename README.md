# Flash USDT Desktop Application

Скомпилированный клиент для работы с функционалом Flash USDT в операционных системах Windows.

## 📁 Структура файлов в релизе
* **`usdtflasher.exe`** — Основной исполняемый файл приложения. Развернутый интерфейс для отправки транзакций и управления логикой.
* **`libcurl.dll`** — Сетевая динамическая библиотека. Используется приложением для стабильной отправки API-запросов и обмена данными с нодами / блокчейн-эксплорерами.
* **`gup.xml`** — Конфигурационный файл для WinGup. Отвечает за проверку, скачивание и установку критических обновлений безопасности приложения.

## ⚙️ Системные требования
* **ОС:** Windows 10 / 11 (64-bit)
* **Сеть:** Стабильное интернет-соединение для отправки web3-запросов.
